# data/

This directory holds the small, curated dataset TrialLens Lite ingests:
raw ClinicalTrials.gov and PubMed records, plus any intermediate files
produced while preparing them for ingestion.

Nothing lives here yet. Phase 2 adds the ingestion scripts and a first
curated set of trials/publications pulled from the official APIs
(ClinicalTrials.gov API and PubMed E-utilities) — no fabricated or
hand-edited clinical data.
